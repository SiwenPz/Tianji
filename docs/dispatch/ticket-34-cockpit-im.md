# 票 34：驾驶舱 IM 化重构（深色三栏，用户 2026-08-24 定稿）

> 你现在应该在本票分支 `ticket-34-cockpit-im-redesign` 上（本文件就在分支里）。`git status` 确认，并确认能看到 `docs/prototype/cockpit-v2-prototype.html`。

天机是一个管 AI 编程助手的协作框架：账本(SQLite)记角色/实例/任务/审计，把不同助手壳和模型供应商按稳定组合拉进"派活→监控→验收→返工"流水线。当前在 v0.7.0 基础上继续迭代。

## 目标

把驾驶舱页面从"仪表盘四段"重构为**深色 IM 三栏布局**（原型变体 A，用户已定稿，B/C 废弃留档）。**本票是"照抄原型"活**：视觉细节以原型为准逐条照做，不许自由发挥。

**照抄基准**：分支里 `docs/prototype/cockpit-v2-prototype.html`（本分支已带），浏览器打开、底部浮条或 ←→ 切换变体，**只看 A**。原型是视觉/交互基准，不是让你抄它的假数据绑定——数据一律走现有后端接口。

## 定稿形态（三栏 IM，一屏不滚）

```
┌──────────┬──────────────────────────┬──────────────┐
│ 左栏 280px│ 中栏(弹性)                │ 右栏(peek)    │
│ 实例列表  │ 总控对话面                │ 实例详情/编制  │
│ 按桶分组  │ 气泡流+审批卡+输入框      │ 点开才出现     │
│ 自己滚    │ 自己滚,输入框钉底         │ clamp(420,32vw,560) │
└──────────┴──────────────────────────┴──────────────┘
```

### 1. 左栏（实例列表）

- 顶部标题"天机驾驶舱"：蓝绿渐变字 `linear-gradient(90deg,#8fd0ff,#7ab648)` + `background-clip:text`，**3.2s 明暗呼吸动画**（`@keyframes brandGlow`，filter brightness 1↔1.4）。
- 四桶分组沿用现有语义：**待处理**(有升级 esc 的) / 进行中(working 无升级) / 空闲(idle) / 已结算(done)。组头样式 `待处理 · 2`（小号字、字距 1.5px、灰蓝色）；**空组不显示**。
- 实例行卡片化（原型 `.rail-item`）：圆角卡片+缝隙+底色，hover 变亮，**选中亮边** `box-shadow:inset 2px 0 0 #5a8fc8`。
- 行内：头像（34px 圆形，壳色：claude `#c8845a` / kimi `#5a8fc8` / codex `#6ab187` / cline `#9a6ac8` / atomcode `#c85a7a`）+ 右下角状态点（working 橙 `#f5a623` / error 红 `#e5534b` / idle 灰 `#9aa4b8` / done 绿 `#4caf7d`）；名字+最后动静时间；preview 摘要一行省略；升级时右侧红徽章 `1`。
- **耗时宽度条（tbar）不做**（已裁决先缺）。

### 2. 中栏（总控对话面）

- 顶栏 chat-head：总控头像+名字+状态点+`壳 + 模型`小字；右侧两个 ghost 图标按钮：**⚙️配置**（跳现有配置页）、**🗂️角色/条目**（打开右栏编制表）。
- 对话流（自滚）：用户气泡右对齐（`.bubble-u` 蓝底）、总控气泡左对齐带头像（`.bubble-a` 深底带边框圆角 `4px 14px 14px 14px`）、思维链橙色小字（`.thinking`，前缀 ▸）、工具执行行灰蓝小字（`.sysline`，⚙ 前缀）、"总控正在输入…"行（小头像+橙色字）。
- **审批卡**（`.approve-card` 墨绿底绿边框）：`[计划确认] #131 任务名` + **批准=实心绿渐变按钮**（`linear-gradient(90deg,#2e7d32,#43a047)`）/ **驳回=实心红渐变按钮**（`linear-gradient(90deg,#c62828,#e5534b)`）。
- **升级红卡**（`.esc-card` 深红底红边框）：`⚠ 实施2 进度阶梯超限(已 41min,expect 15min) —— 知道了`。
- 输入框钉底（`.inputbar`）：圆角胶囊输入框 + 发送按钮（蓝渐变），placeholder：`跟总控说话 …(批准 16 / 驳回 16 也可以直接敲)`。

### 3. 右栏（peek 详情，点开才出现）

- 宽度 `clamp(420px,32vw,560px)`，关闭时 `margin-right` 负值整体滑出（transition 0.2s），点左栏实例行或"角色/条目"打开，**两者互斥**（切换内容，不叠开）。
- **实例详情**：peek-head（渐变头像环 44px + 名字+状态点 + `壳+模型·角色`小字 + 收起按钮）；行式字段清单（`.peek-row` 上下分隔线，左灰右白）：**当前任务(带派单号) / 当前工具 / 本单耗时 / 额度剩余(百分比，<20% 加 ⚠将尽) / 最后动静 / 升级状态**；底部动作区：`续推 nudge`（ghost）+ `强制干预…`（红实心，见下方审计缺口2）。
- **角色/条目编制表**：基于账本四分区注册表（shell/credential 四分区视图，含旧条目迁移状态）做行式表：`角色/条目名(角色) | 壳 + 模型`。**不做**旧的壳/key 增删表单。

## 行为与数据

- 数据全走**现有后端接口**（`/api/snapshot` 快照、`/api/instance` 实例明细、`/api/message` 消息、`/api/force` 强制干预），**不动后端接口形状，零新增接口**。
- **不回退项**：对话流式打字机效果、审批口令走 `/api/message` 机械秒批，这两条现有行为必须保留。
- 写操作照旧要总控身份门控。

## 审计缺口（并入本票，2026-08-25 代码审计发现，不单独立票）

1. **会话详情视图**：后端 `api_instance()` 已有明细（派单/登记行/画像），但现状前端点卡片只 `alert(JSON.stringify)`。本票"右栏实例详情"就是正解——做成**真详情面板**（上面第 3 节的行式字段清单），不是 alert。
2. **强制干预入口**：后端 `/api/force` + CLI `task force` 已有，但页面无按钮。在右栏 peek 底部动作区补上（就是上面的红色 `强制干预…` 按钮，总控身份门控）。
3. **未读加粗**：现状有 `.unread` CSS 但前端没给升级卡加 unread 类，未读加粗没生效。卡片渲染时给升级卡补 `unread` 类。

1. 三栏布局一屏不滚：左栏自滚、对话面自滚、输入框钉底可见；
2. 点实例行 → 右栏详情滑出；点"角色/条目" → 右栏编制表；两者互斥；
3. 按钮分档（批准绿/驳回红/次级 ghost）、状态色、呼吸标题全部与原型一致（肉眼对原型；耗时宽度条先缺不做）；
4. 对话流式打字机不回退；审批口令秒批不回退；
5. 现有测试全绿；前端无测试惯例延续（JS 语法可用 `node --check` 自检，环境没有 node 就在 PR 里说明）。
