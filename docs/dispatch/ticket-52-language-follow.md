## 背景

规格 20.6"语言跟随用户"（2026-08-14 用户补充）：机器生成文本——任务书、启动器提示词、报告要求——语言跟随用户语言（用户用中文则全中文）。当前硬编码中文，无语言检测/切换，多语言场景未落地。

现状锚点：

- `tianji/render.py`：`TASKBOOK_TEMPLATE` 等模板硬编码中文（回报纪律/求助纪律等段落文本同）
- 账本 configs 表：无"用户语言"配置项

## 目标

补语言跟随机制：账本配置记用户语言（默认中文），任务书模板/启动器提示词/报告要求按该语言渲染。**中文环境自洽是底线，多语言是目标。**

## 工作块

1. **账本配置**：configs 表存"用户语言"（默认中文），总控可改带审计。
2. **模板多语言化**：任务书模板、启动器提示词、回报纪律/求助纪律按语言渲染——至少中英两套；缺翻译的语言回退中文并如实标注（产物里注明"本段回退中文"）。
3. **渲染接线**：render 侧读账本用户语言选模板套渲染。
4. 明确不做：自动语言检测（用户语言由用户在配置里明确设定，不自作聪明猜）；不引入 i18n 框架（模板多语言化=纯数据/纯文本，轻量优先）。

## 验收标准

- [ ] 账本配置表存"用户语言"（默认中文），总控可改带审计
- [ ] 任务书模板、启动器提示词、回报纪律/求助纪律按语言渲染（至少中英两套；缺翻译的语言回退中文并如实标注）
- [ ] 反例回归：用户语言=中文时产物全中文；=英文时产物全英文（或回退标注）
- [ ] 全量 `python -m pytest tests -q` 全绿

## 红线

- 只做"跟随用户语言"，不做自动语言检测。
- 模板文本=纯数据，不引入 i18n 框架、不加依赖。
- 账本是唯一写入口，语言配置走账本。
- 简洁优先、精准修改：只动模板与语言读取相关代码。
- 注释、文档一律大白话。
