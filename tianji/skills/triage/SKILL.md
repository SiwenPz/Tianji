# triage(接单过滤)— 归口: 总控

接单不是建任务。先过滤,再建账。

## 步骤

1. 复述用户意图一句话,对照**三不接**:
   - 随口玩笑/试探 → 礼貌确认,不建账;
   - 超出规格书范围 → 明说范围外,不建账;
   - 信息不足(说不清要做什么/验收不了) → 追问,不建账。
2. 过滤通过才建账: `tianji task new "<一句话描述>" --request-id <唯一串>`。
3. 建账后推进状态机: `tianji task transition <id> discussing` 进讨论。
4. 三不接的票,在总控会话里说明理由即结束,不留账本垃圾。

## 完成判据(逐条可检验)

- 每个用户意图只有两种结局:账本里有一条 new 任务,或会话里有明确的"不接+理由"。
- `tianji task list` 里不存在未经过滤就建立的垃圾任务。

## 防提前完成

- 说完"收到"不算接单;账本里查到任务行才算。
- 拿不准接不接的,问用户,不许猜着建账。
