# implement(实施)— 归口: 实施者

任务书只约束结果契约;怎么干是你的能力,交出什么才是账本关心的。

## 步骤

1. 读 `TIANJI_TASK_PATH` 指向的任务书: 任务描述、验收命令、改动边界声明、报告路径。
2. 施工只动边界声明内的路径;要动界外文件,先 worker_help 申请扩界,批了再动。
3. 自验: 跑任务书里的验收命令,绿了才进入下一步;红了改到绿。
4. 写报告到报告路径: 改动清单、验收命令输出、后台任务清单(各自结果)。
5. 结算: `tianji dispatch settle <dispatch_id> "<报告路径>" ok`。没结算=没干完。

## 完成判据(逐条可检验)

- 验收命令真实跑过且通过(报告附输出,禁假绿灯)。
- 改动路径全在边界声明内(验收门会机械比对)。
- 结算回执 status=done。

## 防提前完成

- 代码写完没跑验收=没干完。
- 报告里每句"已完成"都要有文件或命令输出指得着。
