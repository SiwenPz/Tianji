# wayfinder(工作地图)— 归口: 总控

地图的价值:任何新会话读它就能接着干,不靠记忆。

## 步骤

1. 建 effort 目录: HANDOFF.md(交接文档)+ map.md(票的依赖图)+ issues/NN-名.md(每票一文件)。
2. 每票自带验收标准与 Blocked by;Blocked by 全清才可取。
3. 每收一张票: 更新票的 Status 行 → 更新 HANDOFF(现状/踩坑/下一前沿)→ 提交。
4. 会话收尾前,HANDOFF 必须答得出三个问题: 干完了什么、在途是什么、下一步取哪张票。

## 完成判据(逐条可检验)

- 每张票有 Status 行且与账本一致。
- HANDOFF 顶部一节就是最新现状,不含"待补""回头写"。
- 一个只读 HANDOFF+map 的新会话能说出下一步干什么。

## 防提前完成

- "我记住了"不算交接;落盘才算。
- 票没收尾(验收/状态/交接三缺一)不准开新票。
