# tdd(测试先行)— 归口: 实施者

红→绿→重构;没有红的绿不可信。

## 步骤

1. 把任务书验收标准逐条翻成测试,先跑出红(证明测试真的在测)。
2. 最小实现让测试转绿,不顺手做无关功能。
3. 重构只在绿的状态下做,每步重跑。
4. 收尾: 全量测试跑一遍(不只新测试),把红→绿证据写进报告,随 settle 结算落账本。

## 完成判据(逐条可检验)

- 每条验收标准至少一个测试对应,且报告里有"先红后绿"的记录。
- `python -m pytest tests -q` 全绿。

## 防提前完成

- 先写实现后补测试不算 tdd;报告里说不清红在哪=没做。
- 为凑绿而删断言、放宽断言=作弊,审核会按测试真伪维度打回。
