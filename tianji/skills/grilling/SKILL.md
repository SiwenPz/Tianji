# grilling(轮次追问)— 归口: 总控

追问是为了让任务书写得机械可验,不是为了显得严谨。

## 步骤

1. 通读当前意图,列出全部未决点,整轮一次性编号呈出(不问一题等一题)。
2. 每题附推荐答案,用户只回编号+选择即可。
3. 用户答完,把结论固化进任务描述(账本任务行),不留在对话里。
4. 追问轮次入账本(grill_round/grill_answer 消息),可追溯。

## 完成判据(逐条可检验)

- 任务描述里不再有"可能/大概/再说"类未决词。
- 每个未决点都有用户明确答案或明确"按推荐"。

## 防提前完成

- 问一轮就收答案里没覆盖的点,必须再追问一轮或明说"此点搁置"。
- 不许把追问当形式:答案要能直接写进任务书和验收命令。
